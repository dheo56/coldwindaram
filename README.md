# 칼바람 위키 시제품 (다크 테마)

`index.html`을 브라우저에서 열면 시제품을 볼 수 있습니다.

- 위키: 챔피언 / 아이템 / 증강 (요청한 문서 섹션 구성)
- 커뮤니티: 자유게시판 / 베스트게시판
- 추천 20개 이상이면 베스트. 추천 20개 이상인 글은 비추천 20개 이상이어도 베스트 유지.
- 추천 20개 미만이며 비추천 20개 이상인 글은 운영자 전용 숨김 대상.
- 사이트 전체 검정 계열 다크 테마.

**주의:** 현재는 HTML/CSS/JavaScript로 만든 화면 시제품입니다. 회원가입, 로그인, 실제 게시글/댓글 작성 및 저장, 투표, 운영자 권한 관리, 위키 편집 기록은 구현되지 않았습니다. 게시글과 투표 수는 가상 예시입니다. 실제 운영을 위해 서버 및 데이터베이스와 인증/권한 처리가 필요합니다.
